# Imagens

Diretório destinado aos recursos visuais utilizados na documentação.

Podem ser armazenados:

- diagramas;
- esquemas elétricos;
- arquitetura;
- fotografias autorizadas do protótipo;
- imagens de montagem;
- capturas da aplicação.

## Organização sugerida

```text
imagens/
├── arquitetura/
├── hardware/
├── interface/
└── testes/
```

## Convenção sugerida

Utilizar nomes descritivos e evitar arquivos genéricos como `imagem1.png`.

Exemplos:

```text
arquitetura-geral-v1.png
montagem-sensor-entrada.jpg
dashboard-producao.png
teste-e18-solado-preto.jpg
```

## Atenção

Não versionar imagens internas da empresa sem autorização.
