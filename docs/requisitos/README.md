# Requisitos

Documentação dos requisitos do sistema.

- [Requisitos funcionais](funcionais.md)
- [Requisitos não funcionais](naofuncionais.md)

Os IDs dos requisitos devem ser preservados sempre que possível para permitir referência em issues, testes, documentação e apresentações.

Quando um requisito mudar de comportamento, a alteração deverá ser registrada no próprio documento em vez de criar requisitos contraditórios.

## A definir

- necessidade de requisitos de autenticação/perfis;
- requisitos de exportação de relatórios;
- metas quantitativas de disponibilidade;
- meta mínima de precisão da contagem após testes;
- limite aceitável de atraso das atualizações;
- política de retenção histórica.
